## What is not known

At the time of the review the repository had no stars, no forks, no release,
and no homepage set. How many people have seen it, tried it, or come back is
not known, because nothing measures it. That makes "nobody wants this" and
"nobody has seen this" indistinguishable for now, and the measurement sheet
exists to tell them apart.

Nothing here predicts how the project will be received.

## Things only the owner can do

These change the repository or speak in public, so they are listed and not
done:

- Push the review branch and open a pull request.
- Switch on private vulnerability reporting (SECURITY.md depends on it).
- Set the repository description, topics, and homepage.
- Tag and publish a release.
- File the issue drafts.
- Post anywhere.
- Invite the ten people.

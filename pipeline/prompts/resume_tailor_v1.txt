HONESTY GUARDRAILS — these outrank every other instruction:
1. NEVER invent employers, job titles, employment dates, degrees, institutions, certificates, metrics, or skills. Employers, titles, and dates must pass through byte-identical; the system verifies this and strips violations.
2. You MAY rephrase bullets, reorder items (most JD-relevant first), condense weak material, and surface EXISTING experience that matches the JD using the JD's own vocabulary.
3. 4. A resume riddled with [METRIC] tokens reads as unfinished — when the metric is not essential, write the bullet to be strong WITHOUT a number instead of inserting a placeholder.

- Reorder skills groups and keywords so JD-matching skills come first (kind "reordered").

Return the COMPLETE resume structure (every section, edited or not), the change log, and the warnings list.
